# REST API Docs

이 문서는 Weather-Notifier 시스템에서 사용하는 내부 REST API 및 외부 연동 API 규격을 정의합니다.

---

## External API (기상청 공공데이터 API)

우리 프로젝트(날씨 대시보드 및 알림)에서 신청하고 사용해야 할 공공 API는 **딱 1가지**입니다.

### 📌 신청 대상 API: `기상청_단기예보 ((구) 동네예보) 조회서비스`

- **포털 신청 링크**: [공공데이터포털 서비스 바로가기 (data.go.kr)](https://www.data.go.kr/data/15084084/openapi.do)
- **제공 기관**: 기상청
- **서비스 타입**: REST (JSON / XML 지원)
- **기본 엔드포인트 (Base URL)**:  
  `http://apis.data.go.kr/1360000/VilageFcstInfoService_2.0`

---

### 1. 사용할 3가지 핵심 기능(오퍼레이션)

이 서비스 하나만 신청하면 아래 3가지 엔드포인트를 모두 호출할 수 있습니다.

| 기능명 | 상세 경로 (Path) | 발표 시점 | 사용 용도 |
| :--- | :--- | :--- | :--- |
| **초단기실황** | `/getUltraSrtNcst` | 매시 40분 (매시 45분 호출 권장) | **현재 실시간 날씨** (현재 기온, 현재 습도, 1시간 강수량) |
| **초단기예보** | `/getUltraSrtFcst` | 매시 30분 (매시 45분 호출 권장) | **향후 6시간 상세 예보** ("1시간 뒤 비 옵니다" 단기 알림용) |
| **단기예보** | `/getVilageFcst` | 1일 8회 (02:10, 05:10, 08:10, 11:10, 14:10, 17:10, 20:10, 23:10) | **오늘/내일/모레 3일간 예보** (일별 최고/최저 기온, 강수확률) |

---

### 2. 요청 파라미터 (Request Parameters)

모든 엔드포인트 공통 파라미터:

| 파라미터명 | 타입 | 필수 여부 | 예시 값 | 설명 |
| :--- | :--- | :---: | :--- | :--- |
| `serviceKey` | String | **필수** | `발급받은_인증키` | 공공데이터포털 일반 인증키 (Decoding 키 사용 권장) |
| `pageNo` | Integer | **필수** | `1` | 페이지 번호 |
| `numOfRows` | Integer | **필수** | `1000` | 한 페이지 결과 수 (단기예보 파싱을 위해 넉넉히 설정) |
| `dataType` | String | **필수** | `JSON` | 응답 형식 (`JSON` 권장) |
| `base_date` | String | **필수** | `20260929` | 발표 일자 (`YYYYMMDD`) |
| `base_time` | String | **필수** | `0600` | 발표 시각 (`HHMM`) |
| `nx` | Integer | **필수** | `60` | 예보지점 X 좌표 (서울 종로 기준) |
| `ny` | Integer | **필수** | `127` | 예보지점 Y 좌표 (서울 종로 기준) |

> **호출 예시 URL (GET)**:  
> `http://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getUltraSrtNcst?serviceKey=인증키&pageNo=1&numOfRows=10&dataType=JSON&base_date=20260929&base_time=0600&nx=60&ny=127`

### 3. 주요 응답 항목 코드표 (`category`)

기상청 API는 JSON 응답 내 `category` 필드로 데이터 항목을 구분하므로 아래 코드를 매핑하여 사용합니다:

| 코드 (`category`) | 항목명 | 단위 | 설명 / 코드값 |
| :--- | :--- | :---: | :--- |
| **`T1H` / `TMP`** | 기온 (실황: T1H, 예보: TMP) | ℃ | 현재 기온 또는 1시간 단위 예보 기온 |
| **`TMN` / `TMX`** | 아침 최저 / 낮 최고 기온 | ℃ | 단기예보의 06:00(최저), 15:00(최고) 데이터에 포함 |
| **`POP`** | 강수확률 | % | 강수확률 (0 ~ 100%) |
| **`PTY`** | 강수형태 | 코드 | **0**: 없음, **1**: 비, **2**: 비/눈, **3**: 눈, **4**: 소나기 |
| **`SKY`** | 하늘상태 | 코드 | **1**: 맑음, **3**: 구름많음, **4**: 흐림 |
| **`RN1` / `PCP`** | 1시간 강수량 | mm | 강수량 (범주형 텍스트 또는 숫자) |
| **`REH`** | 습도 | % | 상대습도 |
| **`WSD`** | 풍속 | m/s | 풍속 |

---

### 4. 개발 시 필수 주의사항

1. **위경도(GPS) 좌표 변환 (`nx`, `ny`)**
   - GPS 좌표(예: 위도 37.5665, 경도 126.9780)를 기상청 격자좌표(`nx=60, ny=127`)로 변환하는 공식(Lambert Conformal Conic 변환)을 적용해야 합니다.
2. **시각(`base_time`) 계산 로직**
   - 실황 API는 매시 40분 이후에 데이터가 생성되므로, **현재 시각이 45분 미만이면 이전 시간(1시간 전)의 데이터를 요청**해야 `NO_DATA` 에러를 피할 수 있습니다.
3. **인증키 관리**
   - 공공데이터포털 키는 `.env`에 `KMA_API_KEY`로 보관하고, URL 인코딩 중복 방지를 위해 **Decoding 인증키**를 사용하는 것을 권장합니다.
